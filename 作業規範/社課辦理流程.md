# 社課辦理流程

> 依據：《活動辦理辦法》第四條、《組織細則》第十條
> 位階：作業規範（主責部門：活動部；公告後施行，提幹部會議備查）
> 參考：活動 SOP

## 提醒事項

1. 社課開始前務必借好場地，並想好活動流程。
2. 社課結束後務必填寫活動成效表。

## 流程

1. **規劃內容**：提前規劃活動項目與流程；有合作系所時，先與對方活動長討論。
2. **活動系統建檔**：到學校活動系統（event.csu.edu.tw）填寫活動細節、報名時間及時數發放設定。
3. **借用場地**：活動開始前完成場地借用申請。
4. **主持**：擔任主持人，帶動活動氣氛。
5. **拍照**：即使有美宣支援，活動部仍需自行拍照記錄。
6. **整理照片**：挑選清楚合適的照片，上傳雲端硬碟（當屆資料夾 → 活動 → 社課照片 → 建立該次社課資料夾）。
7. **確認人數**：在活動系統二次確認報名人數，並檢查簽到、簽退是否正確。
8. **活動成效表**：填寫完整後上傳雲端硬碟（當屆資料夾 → 活動 → 活動成效表），再寄給課外活動組組長。
9. **發放時數**：每兩天確認一次審核結果；審核通過後，須**手動**發放學員時數（系統不會自動發放）。

## 活動系統操作

- 登入帳號密碼與學校訊息網相同。
- 簽到：活動管理 → 找到當天社課 → 細節（不要修改活動內容） → 簽到 → 電子簽到系統。
- 新增人員：檢視報名名單 → 手動匯入報名名單 → 輸入學號 → 匯入 → 重新整理頁面。

## 成效表撰寫

- 範本中紅框處為需要修改的地方。
- 活動內容應說明流程安排、實際執行情形，以及學員的學習與收穫。
