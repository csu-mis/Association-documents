本會法規分為三級，下級法規不得牴觸上級法規（《組織章程》第五條）：

| 位階 | 文件 | 修改門檻 |

| 章程 | [組織章程](組織章程.md) | 會員大會（全體會員 1/10 以上出席，出席者 2/3 以上同意），經系主任及指導老師確認 |
| 辦法 | [組織細則](辦法/組織細則.md)、[選舉罷免辦法](辦法/選舉罷免辦法.md)、[財務管理辦法](辦法/財務管理辦法.md)、[器材管理辦法](辦法/器材管理辦法.md)、[活動辦理辦法](辦法/活動辦理辦法.md)、[會議規則與幹部計點辦法](辦法/會議規則與幹部計點辦法.md)、[辦公室使用規則](辦法/辦公室使用規則.md) | 幹部會議出席者 2/3 以上同意，經指導老師核備 |

## 修訂方式
1. 提案發起
2. 提案人 fork 專案，並且修改
3. 發起 PR，並於標題和內文說明原因
4. 對所有變更部分，逐一加上 Comment 說明該區段修改原因
5. 依修改文件之位階，召開對應會議（章程：會員大會；辦法：幹部會議），逐條搭配 Comment 進行說明；作業規範由主責部門公告後，於下次幹部會議備查
6. 表決通過後，在開會結束前合併 PR
